# TransformPDF — Descargas

Este repositorio aloja únicamente el instalador de **TransformPDF**, la
app de escritorio para Windows que convierte archivos entre PDF, Word
(DOCX) y Excel (XLSX) sin necesidad de internet.

No contiene código: es solo el lugar donde se publican los
[Releases](../../releases) con el instalador.

- **Código fuente completo**: https://github.com/Felipe-Pocasangre/TransformPDF
- **Descargar la última versión**: [Releases](../../releases/latest)
- **Licencia**: AGPL-3.0 (ver el repositorio de código fuente)

## Requisitos

Windows 10 u 11 de 64 bits. No necesita internet ni cuenta para
funcionar.
